# GitHub 蓝本侦察报告模板

生成报告时默认写入:

```text
.skills/{product}/docs/blueprints/{skill-name}.md
```

没有 activeProduct 时写入:

```text
.skills/blueprints/{skill-name}.md
```

## 模板

```markdown
# GitHub 蓝本侦察:{skill-name}

生成时间:YYYY-MM-DD HH:mm
目标 skill:{skill-name}
来源需求:{REQ-ID 或 无}
当前产品:{product 或 无}
在线侦察状态:完成 / 未完成 / 用户跳过
搜索质量:充分 / 有限 / 不足

## 1. 目标

{一句话描述拟创建 skill 的目标}

## 2. 搜索简报

| 字段 | 内容 |
|---|---|
| 目标动作 | ... |
| 对象 | ... |
| 产物形态 | ... |
| 核心关键词 | ... |
| 英文关键词 | ... |
| 必须命中 | ... |
| 排除方向 | ... |

## 3. 本地查重

| 本地对象 | 路径 | 相关性 | 结论 |
|---|---|---|---|

## 4. 查询记录

| 查询层级 | 查询词 | 来源 | 结果概况 | 备注 |
|---|---|---|---|---|

## 5. 候选对比

| 候选 | 来源 | 许可证 | 维护情况 | 候选评分 | 命中证据 | 可借鉴点 | 不采用点 | 结论 |
|---|---|---|---|---:|---|---|---|---|

## 6. 未纳入候选的结果

| 来源 | 未纳入原因 |
|---|---|

## 7. 最终采用策略

- 借鉴:
- 不借鉴:
- 本项目适配:
- 许可证处理:
- 需要 /create-skill 注意:
- 需要 /review 检查:

## 8. 风险

- ...
```
